# Repositório de Projetos Cursor

Este repositório contém estruturas de pastas para projetos relacionados ao Cursor.

## Estrutura do Repositório

O repositório está organizado em duas pastas principais:

### CursorSample/

Estrutura de projeto de exemplo com as seguintes pastas:

- `assets/` - Recursos estáticos
- `config/` - Arquivos de configuração
- `dist/` - Arquivos de distribuição/build
- `docs/` - Documentação
- `src/` - Código-fonte
- `tests/` - Testes

### LovableCursor/

Contém o subprojeto:

- `lovable-crudclientes/` - Projeto CRUD de clientes

## Status Atual

As pastas estão preparadas com arquivos `.gitkeep` para manter a estrutura no controle de versão. O código-fonte ainda não foi adicionado.

## Como Usar

1. Clone o repositório:
   ```bash
   git clone <url-do-repositorio>
   ```

2. Navegue até a pasta do projeto desejado:
   ```bash
   cd CursorSample
   # ou
   cd LovableCursor/lovable-crudclientes
   ```

3. Adicione seus arquivos de código nas pastas correspondentes.
